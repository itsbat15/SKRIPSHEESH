## 🔍 Numbered Findings List

### [Finding 1] R-02 — Copywriting (Em Dash Character)
- **Priority**: HIGH (Hard Gate)
- **Rule**: R-02
- **Issue**: Karakter em dash (`—`) terdeteksi pada teks UI di beberapa file komponen (`app/dashboard/frontdesk/spp/page.js`, `app/dashboard/frontdesk/pendaftaran/page.js`, `app/dashboard/superadmin/revenue/page.js`, `app/dashboard/frontdesk/page.js`).
- **One-line reason**: R-02 melarang keras penggunaan karakter em dash (`—`) pada seluruh teks UI buatan AI; harus diganti dengan koma (`,`), titik dua (`:`), tanda hubung (`-`), atau tanda kurung `()`.

### [Finding 2] R-27 — UI States (Empty State pada Tabel & Pencarian)
- **Priority**: HIGH (Hard Gate)
- **Rule**: R-27
- **Issue**: Saat pencarian atau filter menghasilkan 0 data pada tabel SPP, tabel Pengguna Super Admin, dan tabel Rekonsiliasi, tabel hanya menampilkan baris kosong tanpa pesan empty state yang informatif.
- **One-line reason**: R-27 mewajibkan setiap komponen tampilan data memiliki 3 status lengkap: Status Kosong (*Empty State*), Status Memuat (*Loading State*), dan Status Kesalahan (*Error State*).

### [Finding 3] R-32 — Keyboard Accessibility (Modal Escape Key)
- **Priority**: HIGH (Hard Gate)
- **Rule**: R-32
- **Issue**: Modal dialog (modal bayar SPP, kuitansi, detail plotting, form tambah user, rekonsiliasi) dapat ditutup via tombol klik X dan Batal, namun belum menangani penekanan tombol keyboard `Escape`.
- **One-line reason**: R-32 mewajibkan seluruh dialog/modal dapat dioperasikan secara penuh melalui keyboard dan dapat ditutup menggunakan tombol `Escape`.

### [Finding 4] R-25 — Color Contrast (WCAG AA Compliance)
- **Priority**: HIGH (Hard Gate)
- **Rule**: R-25
- **Issue**: Beberapa label sekunder berukuran kecil menggunakan warna `text-slate-400` di atas latar belakang putih (`#ffffff`), yang menghasilkan rasio kontras ~2.8:1 (di bawah batas minimum WCAG AA 4.5:1 untuk teks normal).
- **One-line reason**: R-25 melarang teks abu-abu terang pada latar belakang terang dan mewajibkan rasio kontras minimum 4.5:1 untuk teks normal.

### [Finding 5] R-04 — Icons (Generic AI Sparkles Glyph)
- **Priority**: MEDIUM (Purpose-Gate)
- **Rule**: R-04
- **Issue**: Penggunaan ikon `Sparkles` untuk fitur potongan harga/diskon dan cabang teratas pada `pendaftaran/page.js`, `siswa/page.js`, dan `superadmin/page.js`.
- **One-line reason**: R-04 melarang penggunaan ikon generik khas AI (seperti Sparkles/Magic) tanpa alasan relevansi domain; sebaiknya gunakan ikon yang spesifik konteks seperti `Tag`, `Percent`, atau `Trophy`.

### [Finding 6] R-37 — Design Direction (Ketersediaan File DESIGN.md)
- **Priority**: HIGH (Hard Gate)
- **Rule**: R-37
- **Issue**: Proyek belum memiliki file `DESIGN.md` yang secara eksplisit mencatat identitas merek Bimbel Artha, palet warna, tipografi, dan nilai tuas (*dials*).
- **One-line reason**: R-37 mewajibkan adanya file arahan gaya `DESIGN.md` agar antislop dapat memvalidasi desain terhadap identitas spesifik produk, bukan mengasumsikan arahan secara implisit.
